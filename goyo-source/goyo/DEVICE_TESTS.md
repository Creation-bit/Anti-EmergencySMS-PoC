# 실기기 검증 항목

이 문서는 실행하지 않은 수동 검증 항목입니다. JVM 테스트와 APK 빌드 성공만으로 실기기 수신 차단을 검증했다고 판단하지 않습니다.

1. Android 8~16 범위의 대상 기기에서 APK 설치·첫 실행. Shizuku 미설치/미시작 상태의 안내와 비활성화 버튼 잠김 확인.
2. Shizuku 권한 허용·거부·다시 묻지 않음, 서비스 중단·재시작 후 상태 확인. 권한 없는 상태에서 변경이 실행되지 않아야 함.
3. AOSP/Google 수신 앱을 사용하는 기기에서 표시된 패키지 이름과 `adb shell dumpsys package <패키지>`의 `User 0` 상태 비교.
4. 비활성화 전에 원래 `enabled` 값을 기록하고, 비활성화 후 `enabled=3` 확인. 제조사가 거부하는 기기에서는 오류가 표시되어야 함.
5. 복원 후 원래 값과 일치하는지 확인. 원래 기본값(0)이면 1이 아닌 0으로 복원되어야 함.
6. 앱 화면 회전·백그라운드 이동 중 변경이 중복 실행되지 않는지 확인. 앱 프로세스 종료 후에도 복원 기록이 남는지 확인.
7. 기존에 비활성화된 패키지가 복원으로 임의 활성화되지 않는지 확인.
8. 시스템 앱 업데이트·재부팅 후 새로고침으로 현재 상태가 표시되는지 확인.
9. 제조사 독자 수신 앱/업무 프로필/보조 사용자에서 미지원으로 처리되는지 확인.
10. 글꼴 200%, 가로 화면, 화면 읽기 도구에서 버튼·설명·상태 접근성 확인.
11. 앱 삭제 전에 복원하거나 복원 명령을 보관하고, 필요하면 PC에서 복구되는지 확인.

실제 재난문자 전송이나 통신망 조작을 테스트에 사용하지 않습니다. 패키지 상태 검증과 실제 모뎀 수신 여부는 별개입니다.
